    What this is
    
      
    The lab station for Project 1 in your browser: a Niryo One, the platform with its four markers, squares A, B and C, foam cubes and the camera. The project's Python programs run here unchanged, in the browser, with the same windows, keys and robot commands as in the lab.

      3. 
        
    3. Stop works like Ctrl+C. Restart Python is for a program that does not stop.

    Editing your code
    
      
    Open Files and editor, choose a file, edit it and press Ctrl+S. + File and + Folder create new ones in the selected folder (type a path such as LAB-5/main.py to make the folder too); Rename also moves, or drag a file or folder onto another folder (onto the empty space below the list for the top level); Delete removes the selected file or folder. A new .py file appears in the Run list. Your files, dataset, model and results are kept in this browser only: nobody else sees them, and what you add, move or delete does not change anyone else's copy. Another browser or PC starts with fresh files, and clearing the browser's site data deletes yours, so use Download project to keep a copy or move it to a lab PC, and Upload .zip to bring it back. Project 1 is in the AI-VISION-SORTING folder and the labs in LAB-1 to LAB-4; files you delete or move stay that way, and Put back the original program files brings back every original file.
    
      
    The station
    
      
      
        
    • Drag the view to turn it, right-drag to pan, wheel to zoom.
      • 
        
    • Drag a cube to move it, use the wheel over a cube to turn it (Shift = 15° steps), double-click it to remove it. Let go of a cube over hole A, B or C and it drops in; up to 3 cubes stack in each hole. "Add a cube to hole A" puts one straight in.
      • 
        
    • Move the joints by hand opens six joint sliders and gripper buttons. They work while a program has learning mode on (Lab 3 teach mode: move the joints, then press s or g in the terminal), or when no program is connected.
      • 
        
    • Click × on the camera picture to hide it, and Show camera to bring it back.
      • 
        
    • Learning mode (steps 1.1 and 1.4): drag on the platform to move the gripper; click the 3D view, then use the arrow keys (Shift = 5 mm), PgUp and PgDn for height, and [ ] to turn.
      • 
        
    • The camera behaves like the lab's: automatic exposure and colour change when a hand or the arm is in view, and the focus hunts until step 1.3 locks it.
      • 
        
    • Use Desk lamp for the lighting test in step 3 (collect it with --dataset dataset_lighting2).
